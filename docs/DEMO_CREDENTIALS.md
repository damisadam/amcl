## Two-step verification (TOTP)

Platform users and privileged staff (Tenant Admin, approvers, finance posters, KYC/AML reviewers) must enter an authenticator code after the password. All demo staff share the setup key `JBSWY3DPEHPK3PXPAMCLDEMO` (add it to any authenticator app as a time-based key). In demo mode the challenge page also shows the current code in the yellow SIMULATED box. Real users enrol their own key on first sign-in.
